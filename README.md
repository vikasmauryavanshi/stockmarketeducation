# Vikas Maurya Finance Service - Data Analysis Website

A professional finance service website with interactive data analysis capabilities, built with Next.js, TypeScript, and Tailwind CSS.

## 🚀 Features

- **Interactive Data Analysis Dashboard**: Real-time charts and visualizations for market trends, portfolio analysis, and financial metrics
- **Comprehensive Services**: Technical analysis, fundamental analysis, market research, and educational content
- **Responsive Design**: Fully responsive layout that works seamlessly on desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean, professional design with smooth animations and transitions
- **Educational Focus**: All content designed for educational purposes with clear SEBI disclaimer

## 📊 Pages

1. **Home**: Hero section, key metrics, services overview, and call-to-action
2. **Services**: Detailed information about all finance services offered
3. **Data Analysis**: Interactive dashboard with charts showing market trends, portfolio allocation, and sector analysis
4. **About**: Information about Vikas Maurya Finance Service and core values
5. **Contact**: Contact form and business information

## 🛠️ Technology Stack

- **Framework**: Next.js 16 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Charts**: Recharts for data visualization
- **Fonts**: Inter and Poppins from Google Fonts

## 📦 Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## 🌐 Development

Open [http://localhost:3000](http://localhost:3000) in your browser to see the application.
